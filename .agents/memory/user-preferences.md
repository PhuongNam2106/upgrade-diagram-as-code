# User Preferences

## GitHub Operations

- Do not automatically commit, push, create or merge pull requests, dispatch or rerun workflows, publish releases, or change GitHub settings, secrets, variables, and runner labels.
- Prepare code and configuration locally, verify local changes, and provide commands or UI steps for the user to execute.
- Read-only GitHub inspection is allowed when needed for diagnosis; any operation that changes local Git history or remote GitHub state requires the user to perform it.

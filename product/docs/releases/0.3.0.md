# Diagram as Code 0.3.0

## Highlights

- Add a browser Playground at `http://localhost:9000/playground`.
- Support Mermaid, PlantUML, Graphviz/DOT and D2 samples in the Playground.
- Render SVG through the same authenticated Gateway used by the VS Code extension.
- Allow users to save the API key locally, copy diagram source and export the rendered SVG.
- Bundle the Playground into the multi-architecture Gateway image and Windows Server ZIP workflow.

## Install

Download `diagram-as-code-server-0.3.0.zip` and `SHA256SUMS` from GitHub Release `product-v0.3.0`, verify the checksum, extract the ZIP and run:

```powershell
powershell -ExecutionPolicy Bypass -File .\diagram-server.ps1 install
```

Retrieve the generated API key with:

```powershell
powershell -ExecutionPolicy Bypass -File .\diagram-server.ps1 show-key
```

Open `http://localhost:9000/playground`, paste the API key, click **Save**, then render a sample diagram.

## Compatibility

- Windows PowerShell 5.1 and PowerShell 7.
- Docker Desktop using Linux containers.
- Gateway remains bound to `127.0.0.1:9000` by default.
- Existing VS Code extension Preview and Export workflows remain compatible.

## Release Validation

- Full workspace audit, typecheck, tests, builds and release contracts must pass before tagging `product-v0.3.0`.
- The Gateway container must serve the Playground and render an SVG in a Docker smoke test.
- Release artifacts include SHA-256 checksums.

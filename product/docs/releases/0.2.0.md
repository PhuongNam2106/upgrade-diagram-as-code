# Diagram as Code 0.2.0

## Highlights

- Publish-ready VS Code extension: `phuongnam.diagram-as-code-vscode`.
- Windows server bundle: `diagram-as-code-server-0.2.0.zip`.
- Idempotent installer with generated API key, status, logs, restart, update, key rotation and uninstall commands.
- Gateway binds to `127.0.0.1:9000` by default.
- Server manifest locks the Gateway release tag and Kroki/Mermaid `0.31.1` images.
- Update readiness checks and automatic rollback keep the previous installation available when an update fails.

## Install

Install the extension from Visual Studio Marketplace. On the Windows machine, install and start Docker Desktop, download the server ZIP from GitHub Release `product-v0.2.0`, extract it and run:

```powershell
.\diagram-server.ps1 install
```

Use the displayed Gateway URL and API key in the extension. Verify downloaded artifacts against `SHA256SUMS`.

## Upgrade From 0.1.0

Preserve `DIAGRAM_API_KEYS`, stop the old Compose stack, create `%LOCALAPPDATA%\DiagramAsCode\server\.env` with the preserved value, and then install the new Windows bundle. Re-enter the API key in the Marketplace extension because its extension ID has changed from locally packaged development builds.

## Limitations

- Docker Desktop is required on the target Windows machine.
- The initial install and each update require access to public GHCR and the Kroki image registry.
- The installer exposes the Gateway only to the local machine; remote clients require a separately secured deployment.
- The CI workflow covers PowerShell 5.1 and PowerShell 7; package installation still requires a manual Windows acceptance test after images are published.

# Diagram as Code 0.2.1

## Fixes

- Fix Windows PowerShell 5.1 treating normal Docker Compose progress on stderr as a terminating installer error.
- Determine Docker command success from its native exit code while retaining stdout and stderr for real failure diagnostics.
- Add a regression test that runs a successful Docker command which writes pull progress to stderr.

## Install

Do not reuse the Windows Server ZIP from `product-v0.2.0`. Download `diagram-as-code-server-0.2.1.zip` and `SHA256SUMS` from GitHub Release `product-v0.2.1`, verify the checksum, extract the ZIP and run:

```powershell
powershell -ExecutionPolicy Bypass -File .\diagram-server.ps1 install
```

The installer remains idempotent and preserves an existing API key in `%LOCALAPPDATA%\DiagramAsCode\server\.env`.

## Compatibility

- Windows PowerShell 5.1 and PowerShell 7.
- Docker Desktop using Linux containers.
- Gateway remains bound to `127.0.0.1:9000` by default.

## Release Validation

- Installer Pester suite includes 35 tests.
- Full workspace typecheck, tests, release contracts and artifact checksums must pass before tagging `product-v0.2.1`.
